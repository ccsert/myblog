# Signal Archive · 以问题为入口

2026-09-05 · `/archive` 重设计

用户指出 3D 展品与爆炸视图缺少意义，不能带来真正的探索欲。本版撤下造物陈列室，改为围绕真实作品与研究内容的技术档案。视觉依靠高对比字体、留白、细线索引和轻量转场建立科技感。

## 内容与路径

| 之前 | 现在 | 原因 |
| --- | --- | --- |
| 旋转与拆解抽象模型 | 问题标题直接进入项目档案 | 访客先知道内容为什么值得看 |
| 运行演示、点亮收藏 | 读取能力、解释与原始出处 | 每次点击得到具体信息 |
| 四件物件来回切换 | 四个作品与四条研究摘要互相连接 | 有理由继续阅读下一条线索 |
| 浏览者只能逐个尝试 | 类型筛选、多关键词搜索、随机入口 | 同时支持有目标的查找与自由探索 |
| 3D 对象成为页面中心 | 内容排版、悬停扫光、阅读侧栏 | 动效服务阅读与状态变化 |

- 项目与研究元数据继续来自 `portfolio.ts`；来源核对日期沿用 `2026-08-30`，没有把旧快照写成当前版本状态。
- 新增“这个选择意味着什么”是基于既有能力摘要的编辑性解释，不伪装成作者历史复盘，也不添加未经证实的项目能力。
- 研究内容明确标注为摘要，保留原始来源、开放问题与公开边界。
- 档案地址使用 `#read=<slug>`，可直接打开和刷新；相关内容支持浏览器前进 / 后退。
- 关闭阅读面板回到原入口，前往终端会打开对应虚拟文件。

## 实现边界

- 移除上一版新建的 3D 场景、几何展品、收藏状态及相关测试。新 `/archive` 不使用 Canvas、WebGL、模型素材或渲染循环。
- 首页预告和终端入口同步替换；首页既有终端工作台保留。
- 旧像素房间及其状态模块已在后续清理中移除，终端也不再保留旧房间状态；当前 `/archive` 路由不加载旧房间。
- 搜索与内容关系在本地处理，没有增加依赖或外部请求。
- 原生链接、按钮与对话框；键盘打开不播放侧栏动画，减少动效偏好关闭扫光和位移过渡。
- 阅读进度随实际滚动更新，没有模拟加载、虚构状态或完成门槛。

## 验证记录

- ESLint、TypeScript 和 29 项测试通过；新测试覆盖搜索组合、关联内容有效性、深链接与异常链接。
- 浏览器已验证搜索、类型筛选、空结果恢复、随机入口、相关档案切换、浏览器返回、Escape 关闭和焦点恢复。
- 手机阅读采用全屏面板，正文不依赖悬停才能查看。浏览器视口验收不替代实体手机触摸验收。
- 真实浏览器检查 1440×1000、1366×768、768×900、390×844、320×740，页面与最窄阅读面板未出现横向溢出；检查深色、纸色主题及首页预告。
- 默认 Turbopack 生产构建通过。本机生产服务器复验深链接直达与刷新、搜索、筛选、首页进入档案；开发模式额外完成关联跳转、历史返回、键盘随机入口与窄屏终端文件衔接。
- 新档案页检查到 0 个 Canvas；本轮生产预览未记录浏览器 error / warning。测试命令仍有仓库原有的 `next.config.ts` 模块类型提示。

本轮为本地实现，未部署。
