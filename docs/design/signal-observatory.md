# Signal Observatory

2026-09-05 · 本地实现与验收

后续更新：本记录描述首页第一轮实现。档案室已根据后续反馈改为[以问题为入口的技术档案](./signal-index.md)，首页预告随之同步。最终 `/archive` 行为及验收以该记录为准。

沿用终端工作台和可选的 Signal Archive，把个人主页组织成一个能顺着线索深入阅读的信号观测台。

| Before | After | Why |
| --- | --- | --- |
| 居中的站名与技术领域说明 | 非对称大字标题、中文邀请语、线框轨道观测图 | 建立首屏记忆点，并延续现有工程气质 |
| 新访客需要先理解命令或文件树 | 构建、思考、探索三个信号入口 | 可以直接打开项目、知识文件或档案室 |

| 内容列表以分类为起点 | 两个问题引导读者进入具体文件 | 给阅读一个明确动机 |
| 平板窄屏仍挤入三列工作台 | 900px 及以下使用 Shell / Files / Preview 切换 | 保留可读宽度 |
| 手机 Tab 会选中隐藏面板内的控件 | 聚焦候选过滤计算后的 visibility | 避免焦点停留在命令输入框 |

## 实现边界

- 项目与知识名称、文件路径继续来自 `portfolio.ts`；没有增加外部请求或依赖。
- `TerminalHandle.openDocument` 打开现有虚拟文件并切换移动端预览、聚焦工作台、播报文件路径。
- 轨道图由 SVG 与 CSS 构成；信号切换改变轨道朝向，浏览器离屏或标签页隐藏时暂停旋转。
- 提供显式播放/暂停控件；`prefers-reduced-motion` 停止旋转并去除位移动画。键盘打开文档使用即时滚动。
- 档案室入口复用现有场景图；本次没有改动档案室谜题、存档或内容权限。
