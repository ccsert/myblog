# 个人实验场 / Elastic Playground

用户选定了本轮第一张效果图：`exec-faed20ee-7b32-41f0-a906-452600ef43ae.png`，反馈「第一个还不错」。按这张图的构图落地到现有 `/archive`，不新建应用或路由。

## 视觉目标

- 暖白页眉，紧凑的「别只看，动手玩。」引导语。
- 四个连续色块：omz-pm 黄绿、DocBabel 淡紫、Artifact Gateway 暖白、OpenCode Review 橙红。
- 1440 × 1024 目标桌面：页眉 73px、引导区 112px；默认四栏约为 47% / 16% / 16% / 21%；展开项目使用大字名称，保留其余作品的内容预览。
- 标准箭头来自现有 Lucide 图标集，与图稿线形一致。界面使用本地 Inter、JetBrains Mono；omz-pm 大字优先 Arial Black，回退本地 Inter。
- 图稿中的终端、文档、协议名称和代码差异都是可选择、可操作的产品界面文字，没有需要生成的独立插画或照片。没有使用整体截图替代网页，也没有增加 3D 依赖。

## 行为

1. 桌面指针停留 180ms 后展开作品，440ms 宽度过渡。键盘使用方向键、Home、End 切换，切换时不播放宽度动画，焦点中的控件不会被指针自动折叠。按住鼠标拖动或选择文字时不触发展开，点击控件会取消待执行的悬停切换。
2. omz-pm：三个主题示意，切换提示符的结构与配色。图稿提示符实际为 Agnoster 风格，因此默认选中 Agnoster，而非沿用图稿的 Pure 勾选。
3. DocBabel：桌面为可调整宽度的双语对照。点击段落会同时标出另一种语言的对应内容，并在文档内部将其滚动到可见位置；调整视口或阅读空间后仍保持对应。手机使用原文／译文按钮，并直接显示所选段落的另一种语言。
4. Artifact Gateway：切换 npm / OCI / PyPI 原生客户端示例，比较同一份不可变制品内容的首次读取与有效缓存命中。跟随四个节点，查看取回、保存、复用的区别；完成后分别显示本次制品内容回源 1 次 / 0 次，可继续体验下一次读取。明确标注本地示例，域名使用 `.example`，没有发出网络请求，也不模拟真实耗时或协议元数据刷新策略。
5. OpenCode Review：点代码行，打开意见、应用示例建议、重置。明确标注为审查示例，未接入真实 AI 调用。
6. 「作品档案」打开可阅读的原有内容与公开出处，保留 `#read=<slug>`、相关文章、浏览器返回/前进、Escape、焦点恢复和终端文档交接。
7. 手记在作品区下方独立呈现，不占用第一屏。主页入口文案同步为个人实验场。

## 内容阅读与动效

- 八篇档案都有一句关键结论、具体场景、三步流程解读、取舍与关联阅读理由。公开能力与版本仍来自 `portfolio.ts`；`stories.ts` 维护基于这些资料的编辑性解读，没有新增执行结果、截图或性能数据。
- 阅读器沿用作品主题色。桌面使用侧边章节目录，760px 以下改为顶部四个章节按钮；目录、关闭按钮与进度条独立于正文滚动。
- 指针打开采用 260ms 位移与透明度过渡，关闭 180ms，切换文章只做 180ms 淡入。键盘输入立即完成在途动画，Escape 可中断关闭；减弱动态效果设置变化也会停止在途动画。
- 章节按钮只滚动正文，随滚动标记当前章节。打开期间锁定背景滚动，关闭时恢复原来的滚动样式与入口焦点。
- 每篇文章的位置保存在当前标签页的 sessionStorage。关联阅读、关闭后重开与刷新都可恢复；存储不可用或数据损坏时正常阅读，顶部目录可回到开头。位置按当前内容的像素偏移保存，视口变化时受新的正文滚动范围约束。
- 手记通过 IntersectionObserver 在首次进入视野时以 280ms 轻微上移和淡入，条目错开 40ms；默认内容可见，JavaScript 或动画不可用时不隐藏内容。
- 网关路径增加随当前步骤推进的细线，状态文字短暂淡入；应用代码建议时强调新增的 `await`。所有反馈保持原有体验区高度，键盘操作与 reduced-motion 下立即显示状态。

## 适配与边界

- 1100px 以上保留四栏横向橱窗；1099px 以下使用紧凑的四作品切换条和单个体验面板。切换条在作品区顶部吸附，切换作品不主动滚动页面。
- 同一视口下各个作品等高：桌面面板为 `clamp(640px, 100svh - 244px, 960px)`，手机和平板为 `clamp(580px, 100svh - 264px, 780px)`，另加 64px 切换条。标题换行、切换示例或展开评论不会改变作品区总高度。
- 标题、描述、底部编号和「作品档案」独立于滚动区；只滚动中间示例。终端输出、双语文档、代码评论各自可聚焦滚动，操作控件保留在示例边缘。重新选择作品时重置外层示例滚动位置，保留主题、段落和场景选择。
- 600px 以下简化双语阅读控件，320px 仍保留全部功能。
- 动效仅用于展开与悬停反馈，无自动轮播、无无限循环；支持 `prefers-reduced-motion`。
- 真实项目事实继续来自 `app/lib/content/portfolio.ts`。示例文档与代码是本站为解释交互编写的样本，不能视为上游产品截图或真实执行结果。
- 公开事实快照仍为 2026-08-30，没有在本轮声称刷新上游状态。

验收记录见项目根目录 `design-qa.md`。

## 首页与实验场的衔接

首页保留终端工作台，以纸色与四个项目色提前展示实验场。主入口、项目体验入口、档案入口和手记阅读入口分别落到 `/archive`、`#play=<slug>` 与 `#read=<slug>`。`#play=` 只接受四个已知作品，刷新仍能选中正确试玩。

从首页进入时记录位置与入口；使用“返回首页”恢复位置和焦点。作品展开、手记选择通过独立会话键保存，终端首次挂载仅在首页顶部、没有其他焦点或锚点时自动聚焦，避免抢走阅读位置。

首页滚动沿用浏览器原生惯性。目录定位可以被新的滚轮、触摸、指针或键盘输入中断，键盘定位立即完成。顶栏用方向累计阈值减少来回闪现；桌面五章节目录独占正文左侧一列，当前章节和阅读进度分开显示；手机五章节横栏贴合主导航，进入阅读区后保持两层导航相接。章节进度通过按需 requestAnimationFrame 更新直接 transform，布局尺寸由 ResizeObserver 更新。普通正文保持可见，只有章节标题首次进入视野时短暂淡入。
